# Guía de redacción

Esta guía adapta al español las reglas de la skill `simple-english`. Esas reglas siguen el estándar ASD-STE100, el inglés técnico simplificado de los manuales aeronáuticos. Todo texto del atlas sigue esta guía: la interfaz, el README, la taxonomía, las fichas y los actores externos. El script `tools/lint_redaccion.py` encuentra las infracciones que se pueden detectar de forma automática.

## Tipos de texto

El texto descriptivo explica hechos. Cada oración tiene 25 palabras como máximo. Cada párrafo tiene un tema y seis oraciones como máximo. En los campos de las fichas, una línea en blanco separa los párrafos.

El texto procedimental dice al lector qué hacer. Cada oración tiene 20 palabras como máximo y una sola instrucción. El verbo va en imperativo. La condición va antes de la orden, separada por una coma: «Si el script informa errores, corrija las fichas que indica».

Al contar palabras, cada uno de estos elementos vale una palabra: un paréntesis, una cita, un número, una sigla, un nombre propio y un título.

## Lo que no se cambia

No cambie nombres de personas, alias, nombres de organizaciones, nombres de lugares, identificadores, códigos, fechas, cifras, citas textuales, títulos de fuentes ni direcciones web. No cambie los hechos ni su atribución a una fuente. Si la fuente no da una cifra o una causa, conserve la afirmación general.

## Verbos y tiempos

Use la voz activa y nombre al actor: «La Fiscalía acusó a Ovidio Guzmán», no «Ovidio Guzmán fue acusado». Si el actor no se conoce, use la forma impersonal: «lo detuvieron en Culiacán».

Use tiempos simples. No use el pretérito perfecto compuesto: «fue», no «ha sido». No ponga un gerundio después de una coma para agregar un hecho: escriba una oración nueva.

Use «puede» para la posibilidad y «debe» para la obligación. No use «podría», «debería», «quizá», «tal vez» ni «posiblemente». Si un hecho es incierto, diga qué se sabe y qué no: «La fuente no confirma si el frente pertenece al EMC».

## Puntuación y formato

No use punto y coma. No use la raya («—») ni un guion entre espacios para unir dos ideas. Escriba dos oraciones o nombre la relación con «porque», «pero» o «por ejemplo». Un guion dentro de un rango (2024-2026) es correcto.

No use negritas como adorno ni títulos para secciones de dos oraciones o menos. Use una lista vertical solo para tres o más elementos paralelos.

## Una palabra, un significado

Use siempre el mismo término para el mismo concepto:

- Detener y detención para una captura o arresto.
- Designar y designación para los listados oficiales de un Estado.
- «Morir en un operativo», con el nombre de la fuerza, en lugar de «abatir».
- Organización para las entidades del catálogo, facción para sus divisiones internas y célula para sus unidades pequeñas.

## Siglas y términos

Escriba el nombre completo de una sigla la primera vez que aparece en cada ficha. Por ejemplo: «Organización Terrorista Extranjera (FTO, por su sigla en inglés)» y «Oficina de Control de Activos Extranjeros (OFAC) del Tesoro de EE. UU.». No defina los nombres propios de medios o centros de investigación.

Defina un término del oficio en menos de diez palabras la primera vez que aparece: «plaza (territorio de venta de drogas)», «cobro de piso (pago periódico que la organización exige a comercios)».

## Palabras sin contenido

Escriba el hecho, no su importancia. Elimine las palabras que solo marcan importancia, como «crucial», «clave», «fundamental», «significativo» y «poderoso». Elimine también las muletillas, como «cabe destacar», «es importante señalar» y «en este sentido».

Cambie «a fin de» y «con el fin de» por «para». Cambie «asimismo» por «también». Elimine «en conclusión» y «etcétera». No use la fórmula «no solo X, sino Y».
